# استوديو صور المتجر — أحمد الفيفي

تطبيق ويندوز مكتبي لتحضير صور المنتجات للمتاجر الإلكترونية: يقصّ
المنتج عن خلفيته، ويحسّن الصورة، ويضيف الظل، ويقرأ حقائق التغذية،
ويسمّي الملفات وفق اتفاقيات مرنة قابلة للحفظ وإعادة الاستخدام.

**الإصدار الحالي**: 2.9.5

---

## ما يميّز هذا الإصدار: طبقة الوعي الذاتي

البرنامج لا يعالج الصور فقط، بل **يعرف نفسه**: يقيس أداءه، ويكشف
اختناقاته وارتداداته، ويشخّص أعطاله ويصلحها، ويعدّل بنية كوده عند
اللزوم، ويفهم أوامر مالكه بالعربية المحلية وينفّذها فعليًا على مسار
المعالجة.

المرجع التقني الكامل في [`docs/طبقة_الوعي_الذاتي.md`](docs/طبقة_الوعي_الذاتي.md).

| القدرة | الوحدة | الحالة |
|---|---|---|
| الهوية والغرض والحدود | `awareness/identity.py` | مُختبَرة |
| العلامات الحيوية | `awareness/vitals.py` | مُختبَرة |
| السجل ودفتر التغييرات | `awareness/journal.py`, `ledger.py` | مُختبَرة |
| قياس الأداء وكشف الارتداد | `awareness/perf.py` | مُختبَرة |
| التحسين الذاتي المُقاس | `awareness/optimizer.py` | مُختبَرة |
| التشخيص والمداواة | `awareness/healer.py` | مُختبَرة |
| جراحة الكود | `awareness/surgeon.py` | مُختبَرة |
| الحوار العربي | `awareness/dialogue.py` | 10/10 فهمًا |
| جسر الأمر إلى المعالجة | `engine_v2/awareness_bridge_v2.py` | مُثبَت بالبكسل |
| لوحة الوعي (5 تبويبات) | `windows_app/awareness_ui.py` | تعمل |

مبدأ حاكم: **الوعي لا يُعطّل العمل**. كل استيراد لوحدة وعي محميٌّ، وأي
خطأ في الوعي لا يصل إلى مسار معالجة الصور.

## بنية المستودع

```
src/
  awareness/          طبقة الوعي الذاتي (11 وحدة)
  engine_v2/          محرك المعالجة: قص، تحسين، ظل، تغذية، ترخيص
windows_app/          واجهة PySide6 المكتبية
build/windows/        منظومة البناء والتثبيت (PyInstaller + NSIS)
tests/                47 ملف اختبار + الأرشيف
tools/                أدوات تحقّق مساندة
docs/                 الوثائق والأدلّة
```

## التشغيل من المصدر

```bash
pip install -r requirements.txt
python windows_app/native_app_v2.py
```

## الفحص الشامل

```bash
python tests/run_all.py            # كل الاختبارات
python tests/run_all.py awareness  # ما يطابق الاسم فقط
```

النتيجة المرجعية الحالية: **47 / 47 ملفًا ناجحًا** في نحو 201 ثانية.

## بناء المُثبِّت

```bash
pyinstaller build/windows/AhmedAlFaifiMarketImageStudioV2.spec
```

الـspec يكتشف وحدات المشروع تلقائيًا (53 وحدة) و**يفشل صراحةً** إن
غابت وحدة حرجة، منعًا لتسليم برنامج ناقص بصمت. ويتحقق
`tests/test_package_integrity.py` من ذلك قبل البناء.
