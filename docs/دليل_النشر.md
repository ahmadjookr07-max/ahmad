# دليل النشر والتوزيع — Ahmed Al-Faifi Market Image Studio 2.0.0

هذا الدليل يشرح خيارات نشر البرنامج وبيعه: التوزيع المباشر، التوقيع الرقمي (Code Signing)، متجر Microsoft Store، والاشتراطات النظامية في السعودية.

## 1. التوزيع المباشر (الأسرع — جاهز الآن)

ملف **Setup.exe** جاهز للتوزيع فورًا:

1. أرسل Setup.exe للمشتري بأي وسيلة (رابط تحميل، فلاشة، واتساب للأعمال).
2. المشتري يثبّت ويوافق على EULA ثم يرسل لك بصمة جهازه.
3. تصدر له مفتاح التفعيل بعد الدفع (انظر دليل المالك).

**مزايا هذا المسار:** لا رسوم لأي طرف ثالث، تحكم كامل بالتسعير والتراخيص، البيع فوري.

**ملاحظة SmartScreen:** لأن الملف غير موقّع رقميًا بعد، قد يعرض Windows تحذير "Windows protected your PC" — يتجاوزه المستخدم بـ "More info ← Run anyway". لإزالة التحذير نهائيًا انظر القسم التالي.

## 2. التوقيع الرقمي (Code Signing) — يُنصح به بشدة

التوقيع يثبت هوية الناشر ويزيل تحذيرات SmartScreen تدريجيًا ويرفع ثقة العملاء.

| نوع الشهادة | التكلفة التقريبية سنويًا | الأثر |
|---|---|---|
| **OV Code Signing** | 200–400 دولار | يزيل التحذير بعد تراكم سمعة التنزيلات |
| **EV Code Signing** | 300–700 دولار | يزيل تحذير SmartScreen فورًا (سمعة فورية) |

جهات إصدار معروفة: DigiCert، Sectigo، SSL.com، Certum (الأرخص للأفراد). منذ 2023 تتطلب الشهادات تخزين المفتاح في وحدة عتادية (USB Token) أو خدمة توقيع سحابية (مثل SSL.com eSigner أو Azure Trusted Signing بنحو 9.99 دولار/شهر — خيار اقتصادي جيد).

خطوات التوقيع بعد الحصول على الشهادة:
```
signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 /a Setup.exe
```
ويمكن إضافة خطوة التوقيع داخل GitHub Actions ليخرج المثبّت موقّعًا تلقائيًا.

## 3. النشر على Microsoft Store

Microsoft Store يقبل تطبيقات Win32 (مثل تطبيقنا EXE/NSIS) عبر Partner Center:

1. **سجّل حساب مطوّر** في [Microsoft Partner Center](https://partner.microsoft.com/dashboard/registration) — رسوم لمرة واحدة نحو 19 دولارًا (حساب فردي).
2. أنشئ **تطبيقًا جديدًا** واحجز الاسم: Ahmed Al-Faifi Market Image Studio.
3. اختر نوع التطبيق **EXE/MSI (Win32)** وقدّم رابط تحميل مباشر لملف Setup.exe موقّعًا رقميًا (**التوقيع شرط للمتجر**) — أو حوّل الحزمة إلى MSIX.
4. عبّئ صفحة المتجر: الوصف بالعربية والإنجليزية، لقطات شاشة، الأيقونة، سياسة الخصوصية، الفئة (Photo & Video).
5. حدد التسعير: يدعم المتجر البيع المدفوع، أو انشره مجانًا مع التفعيل بمفتاحك الخاص (يُنصح به ليبقى الاشتراك بيدك 100% بلا عمولة متجر).
6. أرسل للمراجعة — عادة 1–3 أيام عمل.

**توصية:** انشر النسخة مجانية التحميل على المتجر مع بقاء التفعيل عبر منظومتك — تكسب انتشار المتجر بلا عمولة 12–15% على المبيعات.

## 4. الاشتراطات النظامية في السعودية

| الجهة | المطلوب |
|---|---|
| **وزارة التجارة / المركز السعودي للأعمال** | سجل تجاري أو وثيقة "العمل الحر" (نشاط برمجيات) لممارسة البيع نظاميًا |
| **منصة العمل الحر** ([freelance.sa](https://freelance.sa)) | وثيقة العمل الحر مجانية للأفراد وتكفي لبيع البرمجيات باسمك |
| **هيئة الزكاة والضريبة والجمارك (ZATCA)** | التسجيل في ضريبة القيمة المضافة إلزامي فقط إذا تجاوزت الإيرادات 375,000 ريال سنويًا، واختياري فوق 187,500 |
| **الفوترة الإلكترونية** | إن سجّلت في الضريبة، أصدر فواتير إلكترونية متوافقة مع فاتورة (ZATCA e-invoicing) |
| **حماية المستهلك** | اتفاقية EULA المضمنة تغطي شروط البيع وعدم الاسترداد — أبرزها للعميل قبل الدفع |
| **حقوق المؤلف (SAIP)** | سجّل البرنامج في الهيئة السعودية للملكية الفكرية (انظر دليل تسجيل الحقوق) |

## 5. قنوات بيع مقترحة

1. **مباشر للمتاجر والسوبرماركت**: زيارات ميدانية وعروض تجريبية — جمهورك المستهدف مباشرة.
2. **متاجر المنتجات الرقمية السعودية**: مثل سلة/زد بإنشاء متجر رقمي يبيع مفاتيح التفعيل.
3. **Microsoft Store**: للانتشار والمصداقية.
4. **مجموعات تجار الجملة والتموينات**: عروض فيديو قصيرة تُظهر معالجة 1000 صورة دفعة واحدة.

## 6. التسعير المقترح (استرشادي)

| الخطة | مدة | سعر استرشادي |
|---|---|---|
| تجريبي | 7 أيام | مجاني |
| شهري | 30 يوم | 99–149 ريال |
| سنوي | 365 يوم | 799–1,199 ريال |
| مدى الحياة (جهاز واحد) | دائم | 1,999–2,999 ريال |

منظومة الترخيص تدعم كل هذه الخطط جاهزة (`trial / monthly / yearly / lifetime`) وأنت تتحكم بالمدة والسعر بحرية كاملة.

## 7. تحديثات البرنامج مستقبلًا

1. عدّل الشيفرة في مستودع GitHub الخاص بك.
2. شغّل workflow البناء (انظر دليل المالك، القسم 6).
3. وزّع Setup الجديد — التراخيص القديمة تبقى صالحة لأن المفاتيح العامة نفسها.
