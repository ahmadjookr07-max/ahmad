# خطة: حزمة تحميل واحدة + نسخ PDF لجميع الأدلة

## الهدف
تجميع كل ملفات التسليم النهائية لبرنامج Market Image Studio 2.0.0 في **ملف ZIP واحد** يُحمَّل مرة واحدة، مع إضافة **نسخة PDF عربية** لكل دليل بجانب نسخته Markdown.

## الوضع الحالي
جميع الملفات جاهزة في `/home/ubuntu/v2_project/delivery/final/`:
- المثبّت `AhmedAlFaifiMarketImageStudio-Setup-2.0.0.exe` (475 MB)
- 6 أدلة بصيغة Markdown (اقرأني أولًا، دليل المالك، دليل المستخدم، دليل النشر، دليل تسجيل الحقوق، تقرير الاختبارات)
- مجلد أدوات المالك السرية (owner_secrets.json + الأداتان)
- الشيفرة المصدرية `MarketImageStudio-2.0.0-SOURCE.zip` (13 MB)

## خطوات التنفيذ

### الخطوة 1: تحويل الأدلة الستة إلى PDF عربي
- تحويل كل ملف Markdown إلى PDF بأداة التحويل المدمجة مع دعم كامل للعربية (اتجاه RTL وخط عربي واضح).
- فحص بصري لعينة من صفحات كل PDF للتأكد من سلامة الحروف العربية والجداول والاتجاه؛ وعند أي خلل أستخدم مسارًا بديلًا (HTML منسق RTL ثم WeasyPrint).

### الخطوة 2: تنظيم بنية الحزمة الموحدة
```
MarketImageStudio-2.0.0-Delivery.zip
├── AhmedAlFaifiMarketImageStudio-Setup-2.0.0.exe
├── اقرأني_أولًا.pdf (+ .md)
├── الأدلة/            ← 5 أدلة × نسختين (PDF + Markdown)
├── أدوات_المالك_السرية/  ← owner_secrets.json + owner_license_tool.py + inject_keys.py
└── MarketImageStudio-2.0.0-SOURCE.zip
```

### الخطوة 3: الضغط والتحقق
- إنشاء ملف ZIP واحد (حجم متوقع ~490 MB بسبب المثبّت).
- اختبار سلامة الأرشيف وحساب بصمة SHA-256 له.

### الخطوة 4: التسليم
- إرسال ملف ZIP الواحد مع قائمة المحتويات والبصمة، ونسخ PDF مرفقة أيضًا بشكل منفصل لسهولة الاطلاع المباشر.

## افتراضات
- "جميع الملفات" = حزمة التسليم النهائية المرسلة سابقًا (المثبّت + الأدلة + أدوات المالك + المصدر)، دون النسخة المحمولة Portable (اختيارية ومتاحة من GitHub مباشرة).
- "نسخة PDF" تخص الأدلة النصية الستة فقط؛ الملفات البرمجية والمثبّت لا تُحوَّل بطبيعتها.

## مخاطر
- حجم الحزمة النهائية كبير (~490 MB) فقد يستغرق تحميلها دقائق حسب سرعة الإنترنت.
- جودة العربية في PDF تُضمن بخطوة الفحص البصري قبل التسليم.
